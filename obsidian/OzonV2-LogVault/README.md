# Ozon V2 Log Vault

这是 Ozon V2 项目的 Obsidian 专用日志库。

打开方式：

1. 打开 Obsidian。
2. 选择 `Open folder as vault`。
3. 选择这个目录：

```text
E:\ozon-V2工作区\ozon-v2自动化运行\obsidian\OzonV2-LogVault
```

本日志库只记录项目操作、架构决策、规则变更和执行证据。它不放业务代码，不放旧插件内容，不作为运行数据目录。
