# Ozon V2 工具台阶段导航设计 (Workbench Stage Navigation Design)

## 目标 (Goal)

让用户在同一批次内自由切换批次总览、供应商审核、图片处理和上传草稿页面。返回批次总览时不得隐藏或丢失供应商审核入口，也不得被系统立即强制跳回审核页。

## 导航结构 (Navigation)

所有工具台页面顶部使用同一条固定阶段菜单：

1. 批次总览 (Batch)
2. 供应商审核 (Supplier Review)
3. 图片处理 (Images)
4. 上传草稿 (Upload)

当前页面高亮。菜单在桌面端横向排列；窄屏允许换行，不遮挡正文。

## 页面行为 (Behavior)

- 批次总览始终可进入；从阶段页返回时使用 `/?run_id={run_id}` 保留当前批次。
- 供应商审核使用当前批次 ID，地址为 `/batches/{run_id}/supplier-review`。
- 工具台读取到 `supplier_review` 状态时只更新状态和菜单，不再执行 `window.location.assign` 强制跳转。
- 当前批次 ID 使用 URL 参数与现有 `localStorage` 双重恢复；从直接打开的审核页返回总览后，菜单仍能恢复审核页链接。
- 图片处理和上传草稿尚未实现页面时显示为禁用菜单项，不创建空白页面，也不伪装成已完成能力。
- 切换页面使用当前浏览器标签页，不自动打开新窗口。
- 供应商审核表单数据仍保存到运行目录中的 `supplier_review.json`，页面切换不清空已保存数据。

## 边界 (Boundaries)

本次只修改工具台和供应商审核页的公共导航及强制跳转逻辑。不会修改：

- Ozon 采集和中国跨境店判定；
- 1688 采集合同与直连 Playwright worker；
- 图片处理实现；
- 上传草稿和发布锁；
- 旧插件。

## 验收 (Acceptance)

- 在供应商审核页点击“批次总览 (Batch)”后停留在工具台，不被自动跳回。
- 在工具台点击“供应商审核 (Supplier Review)”能返回同一批次的审核页。
- 两个页面都显示相同菜单，并正确高亮当前页面。
- 图片处理和上传草稿显示禁用。
- 现有供应商审核 API、链接输入和采集按钮行为保持不变。
- 自动化测试覆盖菜单链接、取消强制跳转和当前批次链接恢复。
