# Ozon V2 价格与包装证据工作区设计

## 背景

Ozon V2 当前上传草稿页直接展示类目字段映射与逐商品上传门禁，没有一个稳定的前置区域让用户确认真实采购成本、包装尺寸、包装重量和目标利润。因此存在三个问题：

1. 用户无法在工作台内得到可审计的实际建议上架价。
2. 包装长、宽、高和重量没有形成受控证据，后续字段草稿仍可能把相关字段留空。
3. 批次中的商品状态互相干扰；一个商品未完成时，不应阻塞已经完成的其他商品。

本设计采用用户确认的 C 方案：上传草稿页最前面增加“左侧商品清单 + 右侧稳定编辑区”。编辑区不自动折叠，不因后台刷新跳回初始状态，每件商品独立保存、独立推进。

## 目标

1. 在上传草稿页的类目映射区域之前增加全宽“价格与包装证据”工作区。
2. 用户逐商品填写采购价、国内运费、包装长宽高、包装重量和目标净利润率。
3. 读取店铺级固定参数和 GUOO 陆空规则，精确计算跨境运费、总成本、建议上架价和划线价。
4. 显示可点击的 1688 商品链接、已锁定 SKU 和采集参考价，方便用户核对；采购价始终以人工填写值为准。
5. 把包装尺寸和包装重量保存为后续字段草稿可消费的人工确认事实。
6. 每件商品独立确认；已完成商品可以先进入字段草稿，不等待整批。
7. 继续保持发布锁：本功能只准备价格和字段证据，不自动上传、发布或最终审批。

## 不在本次范围

- 不新增真实采购、仓储、质检、开票或其他未确认费用。
- 不改变图片生成、图片审核、真实采集或供应商 SKU 锁定流程。
- 不自动调用 Ozon 上传或发布 API。
- 不抓取实时汇率；使用店铺设置中的固定换算参数，并在每次确认记录中保存参数快照。
- 不把采购价、国内运费或利润率写入 Ozon 商品属性字段。

## 页面布局

### 页面位置

“价格与包装证据”放在当前上传草稿页的批次摘要之后、类目模板自动映射结果之前。现有字段草稿区和右侧逐商品上传门禁继续保留。

### 左侧商品清单

左侧固定展示本批次全部商品，顺序与上传草稿商品顺序一致。每项显示：

- 商品序号和简短标题；
- `未填写`、`待确认`、`已确认` 或 `计算失败`；
- 已确认时显示建议上架价；
- 当前选中项高亮；
- 已确认项使用绿色状态标识。

切换商品仅由用户点击触发。后台轮询或数据重新渲染不得改变当前选中商品，也不得清空尚未提交的输入。

### 右侧稳定编辑区

右侧始终显示当前商品，不使用自动收起的折叠面板。内容分为四块：

1. **商品与供应商核对**
   - Ozon 商品标题和主图；
   - 当前锁定的 1688 SKU；
   - 1688 商品 URL，可在新标签页打开；
   - 1688 采集参考价，明确标注“仅供核对，人工采购价优先”。
2. **用户输入**
   - 采购价，人民币；
   - 国内运费，人民币；
   - 包装重量，克；
   - 包装长度、宽度、高度，厘米；
   - 目标净利润率，百分比。
3. **固定参数与计算明细**
   - Ozon 佣金率：当前固定 15%；
   - 包装/标签费：当前固定 2 元；
   - 物流规则：GUOO 陆空标准；
   - 店铺固定汇率及取整规则，只读显示；
   - 跨境运费、总成本、原始售价、取整后售价、卢布上架价和划线价。
4. **确认动作**
   - `确认并写入本件价格与包装证据`；
   - 成功后只更新当前商品；
   - 保存成功后保留当前编辑区，不自动跳走；用户可主动选择下一件。

## 输入与固定参数

### 每件商品由用户填写

| 字段 | 单位 | 约束 |
| --- | --- | --- |
| 采购价 | CNY | 大于 0；采集价不自动写入 |
| 国内运费 | CNY | 大于等于 0 |
| 包装重量 | g | 大于 0 |
| 包装长度 | cm | 大于 0 |
| 包装宽度 | cm | 大于 0 |
| 包装高度 | cm | 大于 0 |
| 目标净利润率 | % | 大于等于 0，且与佣金率相加后小于 100% |

目标利润率可以从店铺默认值预填，但仍要求用户对当前商品点击确认。采购价默认留空，1688 采集价只作为旁边的参考信息。

### 店铺级固定参数

- Ozon 佣金率：15%；
- 包装/标签费：2 CNY；
- 物流渠道：GUOO 陆空标准；
- CNY 到 RUB 的店铺固定换算参数；
- 上架价与划线价取整规则；
- GUOO 规则版本。

确认记录保存这些固定参数的快照，避免以后调整店铺设置后无法解释历史价格。

## 运费与售价计算

### GUOO 运费

沿用 `ozon_v2.domain.cel_freight` 中已经验证的 GUOO/CEL rFBS 规则。用户只填写包装重量和长宽高；成交价分档使用系统计算出的卢布上架价，不再要求用户重复输入。

由于 GUOO 分档与卢布成交价有关，而卢布上架价又受运费影响，后端采用有限迭代：

1. 使用 Ozon 参考价或最低分档作为初始成交价；
2. 按当前成交价、包装重量和尺寸选出 GUOO 陆空标准报价；
3. 使用该运费计算建议售价，再按店铺固定参数换算为 RUB；
4. 用新的 RUB 售价重新选择分档；
5. 分档不再变化即收敛；最多执行五轮。

如果五轮内未收敛、落入资费空档或尺寸重量不符合任何可用渠道，系统不得猜测运费，也不得允许确认。页面显示具体失败原因和超出的限制。

### 成本公式

```text
跨境运费 = GUOO 陆空标准规则(卢布上架价, 包装重量, 长, 宽, 高)

总成本 =
    采购价
  + 国内运费
  + 2 元包装/标签费
  + 跨境运费
```

不加入采购附加费、入库质检费、仓储分摊等当前已经确认排除的成本。

### 建议售价

```text
原始建议售价 CNY =
  总成本 / (1 - Ozon 佣金率 - 目标净利润率)
```

当前 Ozon 佣金率固定为 15%。计算完成后按照已确认的上架价规则向上取到 `.90`，再根据店铺固定换算参数生成 RUB 上架价。划线价按上架价除以 `0.8` 计算，再应用相同的向上取整策略。

首件商品验算：

```text
采购价        9.90
国内运费      7.00
包装/标签费   2.00
跨境运费     16.952
总成本       35.852

35.852 / (1 - 0.15 - 0.20) ≈ 55.156923
向上取 .90 = 55.90 CNY
```

卢布上架价必须由实际店铺换算参数生成，页面不能把示例换算值写死。

## API 与服务边界

### 读取

`GET /api/batches/{run_id}/upload` 在每件商品中增加：

- `pricing_evidence`；
- `pricing_status`；
- `pricing_ready`；
- `supplier_url`；
- `supplier_reference_price`；
- `store_pricing_parameters`；
- `pricing_summary`。

### 预览计算

`POST /api/batches/{run_id}/pricing-evidence/preview`

请求包含 `seed_id` 和七个用户输入字段。服务端校验并返回权威计算结果，但不持久化。前端可以即时显示输入变化，最终结果仍以服务端返回为准。

### 确认保存

`POST /api/batches/{run_id}/pricing-evidence/confirm`

服务端重新执行全部校验和计算，不信任前端预览结果。保存成功后：

1. 写入当前商品价格证据；
2. 把包装尺寸和包装重量加入当前商品的人工确认事实；
3. 重新计算当前商品字段映射和门禁；
4. 若该商品已有旧上传草稿，只使当前商品草稿失效，其他商品不受影响；
5. 返回当前商品最新状态和批次价格完成数量。

## 字段证据流

价格证据分为两类：

### 可进入 Ozon 属性映射的人工事实

- `package_weight_g`；
- `package_length_cm`；
- `package_width_cm`；
- `package_height_cm`。

映射服务只允许把这些事实写入语义明确匹配的包装字段，例如“包装重量”“包装长度”“包装宽度”“包装高度”。包装尺寸不得覆盖商品本体尺寸，包装重量不得冒充商品净重。

### 只进入价格草稿的成本事实

- 采购价；
- 国内运费；
- 目标净利润率；
- 跨境运费；
- 总成本；
- CNY/RUB 建议售价；
- 划线价；
- 固定参数快照。

这些字段不作为商品属性上传，但要进入上传草稿中的价格部分和审计证据。

## 门禁与逐商品推进

每件商品新增 `pricing_ready` 门禁。单件商品只有在以下条件全部满足时才可构建上传草稿：

- 类目模板就绪；
- 必填属性就绪；
- 原创内容就绪；
- 图片门禁通过；
- 价格与包装证据已确认。

门禁按商品独立计算。两件商品已满足时，允许只构建这两件，不等待另外三件。

确认价格不会触发上传。现有 `Publish Lock Active` 继续保留，最终发布仍需用户单独确认。

## 状态与错误处理

### 状态

- `missing`：尚未填写；
- `draft`：页面有输入但尚未确认；
- `confirmed`：服务端计算成功并已保存；
- `invalid`：输入或物流规则不合法；
- `stale`：店铺固定参数或已锁定 SKU 发生变化，需要重新确认。

### 校验错误

- 金额、尺寸或重量为空、非数字或超出允许范围；
- `佣金率 + 目标利润率 >= 100%`；
- 店铺汇率缺失；
- 没有符合尺寸、重量和成交价的 GUOO 陆空标准报价；
- 运费与售价有限迭代未收敛；
- 供应商 SKU 尚未锁定；
- 保存时商品或参数版本已变化。

错误只影响当前商品。页面保留用户输入，明确显示需要修改的字段，不自动折叠、不跳转、不清空整批。

## 测试与验收

### 领域计算测试

- 首件商品输入得到跨境运费 `16.952`、总成本 `35.852`、原始售价约 `55.156923` 和取整售价 `55.90`；
- GUOO 分档边界和体积重规则继续与现有资费测试一致；
- 成交价导致分档变化时能够收敛；
- 无可用渠道和不收敛时明确失败；
- 佣金与利润率分母非法时拒绝计算；
- 所有货币计算使用 `Decimal`，不使用二进制浮点数。

### 服务与持久化测试

- 单件预览不写文件；
- 单件确认原子保存并可重新读取；
- 更新一件不改变其他商品；
- 重复提交相同输入得到相同结果；
- 店铺参数变化后旧记录标记为 `stale`；
- 包装尺寸和重量只映射到语义匹配的包装字段；
- 确认一件只刷新当前商品草稿和门禁。

### 页面合同测试

- 上传页包含价格前置工作区；
- 左侧显示五件商品及独立状态；
- 右侧编辑区没有自动折叠；
- 展示可点击 1688 URL、参考价和已锁定 SKU；
- 展示七个用户输入、固定参数、公式明细和确认按钮；
- 重新渲染后保留当前商品和未提交输入；
- 已确认商品可以独立进入后续字段草稿。

### 安全边界

验证只使用测试夹具和本地临时运行目录。不得触发真实采集、生图、上传、发布或最终审批。
