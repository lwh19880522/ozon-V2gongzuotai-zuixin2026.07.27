# 浏览器任务结果确认设计 (Browser Task Result Acknowledgement Design)

日期 (Date): 2026-07-11

状态 (Status): 用户已批准继续实施 (Approved For Implementation)

## 问题 (Problem)

当前扩展把标签页复用和消息送达展示成采集进展。内容脚本即使停在搜索页、没有提交结果，后台心跳仍会覆盖真实阶段，工作台因此看似运行但没有结果文件。

## 最小设计 (Minimal Design)

1. 浏览器后台只负责分发任务，不把消息送达视为采集成功。
2. 内容脚本返回真实执行结果；搜索阻塞必须返回失败结果和明确代码。
3. 同一任务没有新分发令牌时，后台不再用 `tab_reused` 心跳覆盖内容脚本阶段。
4. 搜索卡片优先使用中国跨境证据；卡片证据不足时，在同一受控标签页中有限检查候选详情，最终仍只接受高置信中国跨境证据。
5. 唯一成功条件仍是后端验收并生成 `attribute_template_result.json` 与后续 `ozon_collection_result.json`。

## 边界 (Boundaries)

- 不改旧插件。
- 不增加前端框架或新服务。
- 不放宽中国跨境店验证。
- 不把标题、页面跳转或在线心跳当作采集结果。

## 验证 (Verification)

- Node 回归测试覆盖失败回执、静默复用与跨境卡片信号。
- Python 全量测试覆盖结果验收边界。
- 当前批次实战必须生成真实结果文件，否则报告精确阻断原因。
