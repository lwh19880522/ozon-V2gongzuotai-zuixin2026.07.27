# Ozon 逐槽参考生图设计

## 目标

把“参考 Ozon 图片学习构图”固化在 `ozon-product-media-generator` Skill 内。工作台只提供证据并承载结果，不承担构图选择、参考图映射或生图调度逻辑。

每件商品仍生成：

- 1 张白底主体锚点，仅用于锁定真实商品；
- 1 个 1×2 网格，裁成 `main_01`、`main_02`；
- 2 个 1×3 网格，裁成 `detail_01` 至 `detail_06`；
- 八张成品全部为精确 3:4 竖图。

## 真实商品与视觉参考分工

白底主体锚点和锁定的 1688 原图负责商品真实性。任何输出都必须保持已确认 SKU 的数量、套装组成、颜色、轮廓、比例、结构、零件、配件、印刷和包装内容。

Ozon 原商品图片只负责逐槽提供以下视觉蓝图：

- 主体在画面中的位置和占比；
- 镜头角度、景别和裁切方式；
- 背景、场景、光线和色彩气氛；
- 留白、信息区和视觉动线；
- 主图或附图的信息层级。

不得复制 Ozon 参考商品本身、品牌、文字、徽章、水印、价格或不属于锁定 SKU 的零件和功能。

## 逐槽一对一映射

八个成品槽位必须各自绑定一个 `primary_ozon_reference`。一个槽位只学习自己的主参考图，不把多张 Ozon 图混合成模糊的平均风格。

默认按 Ozon 图库的有效顺序映射：

1. 第 1 张有效参考图 → `main_01`
2. 第 2 张有效参考图 → `main_02`
3. 第 3 至第 8 张有效参考图 → `detail_01` 至 `detail_06`

映射前排除加载失败、像素重复、非商品内容和无法辨认构图的图片。Ozon 有八张以上有效图片时，每个槽位使用不同参考图。少于八张时，Skill 可为缺口选择最接近该槽位用途的已用参考图，但同一参考图最多绑定两个槽位，并记录 `reference_reused=true`；复用时仍必须改变买家问题或景别，避免近重复成品。

每个槽位在生成前写出结构化蓝图：

- `reference_path`
- `reference_sha256`
- `subject_position`
- `subject_scale`
- `camera_family`
- `shot_scale`
- `background_family`
- `lighting_family`
- `negative_space`
- `copy_zone`

## 网格生成

白底主体生成完成并校验后：

- 1×2 主图调用同时输入白底主体、`main_01` 主参考图和 `main_02` 主参考图，并明确“参考图 A 只对应左面板，参考图 B 只对应右面板”。
- 第一个 1×3 调用输入白底主体和 `detail_01` 至 `detail_03` 的三张主参考图，按左、中、右逐一对应。
- 第二个 1×3 调用输入白底主体和 `detail_04` 至 `detail_06` 的三张主参考图，按左、中、右逐一对应。

整张 1×2 网格保持 3:2，整张 1×3 网格保持 9:4。裁切后每个面板必须为精确 3:4。

## 验收与返修

槽位收据增加：

- `primary_ozon_reference_sha256`
- `reference_slot_index`
- `reference_reused`
- `reference_composition_followed`
- `locked_subject_preserved`

验收必须同时确认：

1. 锁定商品真实主体未被参考商品替换；
2. 画面构图、景别、光线、背景和信息区明显对应自己的主参考图；
3. 未复制参考图文字、品牌或不真实商品信息；
4. 八张图不存在像素近重复；
5. 俄文仍由本地渲染器添加，图像模型不直接生成文字；
6. 成品比例仍为精确 3:4。

单槽返修沿用该槽原来的 `primary_ozon_reference`。只有用户明确要求更换参考图，才允许改变映射；返修不得影响其他已验收槽位。

## 边界

- 本设计只修改 Ozon 生图 Skill、提示词资产和对应契约测试。
- 工作台继续只提供 Ozon 参考图、1688 真实证据、SKU/主体锁定结果并显示生成结果。
- 不在工作台命令里实现参考图分析和生成逻辑。
- 不自动上传、发布或最终审批。
