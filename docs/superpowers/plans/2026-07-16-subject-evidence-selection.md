# Subject Evidence Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the incorrect pre-existing white-background gate with user-selected multi-image supplier subject evidence and make the image Skill generate the clean white-background master.

**Architecture:** Keep the current supplier SKU receipt, state machine, image queue, and storage filenames. Extend the existing subject contract with multiple verified source files while preserving legacy singular fields. The collection-review UI submits selected supplier evidence images; the image Skill performs white-background conversion before the existing 1x2 and 1x3 generation flow.

**Tech Stack:** Python 3.11, dataclasses, local JSON artifacts, SQLite image queue, HTML/CSS/JavaScript generated by `local_server.py`, pytest/unittest, Codex Skill Markdown and fixed prompt assets.
